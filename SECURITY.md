# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to **admin@meridianprotocol.site**. Include the affected contract/address, a description, reproduction steps, and potential impact. Do not include private keys, seed phrases, passwords, OTPs, or API credentials.

Please do not exploit an issue against mainnet contracts or disclose it publicly before the project team has had a reasonable opportunity to review it.

## Audit status

No independent third-party audit has been commissioned. Source verification on an explorer, if present, confirms source-to-bytecode correspondence; it is not a security audit. The project's internal analysis is in `docs/THREAT_MODEL.md` and `docs/SECURITY_REVIEW.md`.

No formal bug-bounty program currently exists. This policy does not promise a reward.
