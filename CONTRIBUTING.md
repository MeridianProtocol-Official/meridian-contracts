# Contributing to Meridian Protocol

## Current Status

Meridian Protocol is currently developed and maintained by the core team. **There is no formal external-contributor program in place at this time.**

## Feedback & Suggestions

While we're not accepting pull requests for deployed contract modifications, we welcome:

- **Bug reports** (via responsible disclosure in [SECURITY.md](SECURITY.md))
- **Documentation improvements** suggestions
- **General feedback** and questions
- **Discussion of potential partnerships**

Please contact: **admin@meridianprotocol.site**

## Important Notes

⚠️ **Please DO NOT submit pull requests that:**

1. Modify deployed contract source code
2. Change the MRDN token implementation
3. Alter staking, vesting, or treasury contracts

Deployed contracts are immutable and their source in this repository is preserved to match what is verified on BscScan. Any changes to deployed contracts would require a new deployment at a new address.

As the project matures, we plan to:

- Establish a formal contributor code of conduct

Updates on these initiatives will be shared through official channels.
